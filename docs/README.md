## Directory model

- `foundation/`: durable intent and binding principles
- `context/`: task-to-knowledge routing for humans and AI tools
- `architecture/`: target architecture and capability contracts
- `decisions/`: accepted and proposed architecture decisions
- `governance/`: delivery and documentation controls
- `reference/`: shared terminology
- `reference-applications/`: real products used to validate Forge without becoming platform core
- `source-material/`: preserved, non-normative manuscripts and their retrieval maps

Every document declares a status and owner. Only Accepted documents are normative. Proposed documents are review material; Draft documents are incomplete.
