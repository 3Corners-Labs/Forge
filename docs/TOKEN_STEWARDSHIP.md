# Token Stewardship

> **Historical Draft:** this document is preserved as consolidation source and is not normative. Its concepts are being consolidated into [`docs/architecture/intelligence.md`](architecture/intelligence.md); only Accepted documents have authority.

Tokens are enterprise resources.

Principles:
- Minimize prompt size.
- Reuse validated context.
- Avoid duplicate reasoning.
- Select the smallest capable model.
