# Engineering Language

> **Historical Draft:** this document is preserved as consolidation source and is not normative. Its concepts are being consolidated into [`docs/reference/glossary.md`](reference/glossary.md); only Accepted documents have authority.

## Canonical Language

English is the canonical engineering language for Forge.

It SHALL be used for:
- Source code
- APIs
- Architecture
- ADRs
- Documentation
- Pull requests
- Commit messages

User-facing content SHALL be localized through resource files rather than embedded in source code.
